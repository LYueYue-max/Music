# 圆音 · 圆润简洁清爽音乐库（纯前端演示版）

一个可直接部署到 **GitHub Pages** 的纯静态音乐网站演示项目，无需后端、无需数据库、无需构建工具。

- 主题：圆润、简洁、清爽
- 视觉：大圆角卡片、柔和配色、充足留白、轻阴影、统一圆角按钮
- 两套独立界面：**管理员界面** 与 **普通用户界面**（普通用户看不到任何管理员入口）
- 播放器：圆润方形卡片式弹窗，支持静默加载、拖动、最小化、播放列表、循环/随机、音量记忆

## 一、目录结构
├── index.html # 页面入口（含路由挂载点、Toast、Modal、播放器容器）\n
├── css/\n
│ └── style.css # 全部样式（圆润主题 + 响应式）
├── js/
│ ├── utils.js # 工具函数（校验、转义、Toast、对话框、时间格式化）
│ ├── store.js # 数据层（localStorage + 前端哈希）
│ ├── auth.js # 登录 / 注册 / 密码校验
│ ├── player.js # 音乐播放器弹窗
│ ├── admin.js # 管理员界面全部面板
│ ├── user.js # 普通用户 / 游客界面
│ └── app.js # 路由守卫、倒计时、启动逻辑
└── README.md
